Step 1: ネットワーク設計 (VPC)
今回構築するネットワークの全体像です。

VPC (Virtual Private Cloud): AWSの中に作る、あなた専用の独立したネットワーク空間です。

パブリックサブネット: インターネットからアクセス可能なエリア。ここに**EC2（Webサーバー）**を置きます。

プライベートサブネット: インターネットから直接アクセスできない安全なエリア。将来的にデータベースをここに移動させると、セキュリティが格段に向上します。（今回は準備だけしておきます）

インターネットゲートウェイ (IGW): VPCとインターネットをつなぐ出入り口です。

Step 2: VPCの作成手順（VPCウィザード）
AWSには、これらを一括で推奨設定で作ってくれる便利な機能があります。これを使えばミスなく美しい構成が作れます。

AWSコンソールにログインし、左上の検索バーで「VPC」と入力してサービスを選択します。

ダッシュボードにあるオレンジ色のボタン 「VPC を作成」 をクリックします。

以下の設定で作成を進めてください。

設定項目:

作成するリソース: VPC など （これを選択するとサブネット等も自動で作られます）

名前タグの自動生成: olist-project （任意のプロジェクト名）

IPv4 CIDR ブロック: 10.0.0.0/16 （デフォルトのままでOK）

アベイラビリティーゾーン (AZ) の数: 1

解説: 学習用・コスト節約のため「1」にします。商用本番で「絶対に落としてはいけない」場合は「2」にして冗長化します。

パブリックサブネットの数: 1

プライベートサブネットの数: 1

NAT ゲートウェイ: なし

重要: これを有料（あり）にすると高額な料金がかかります。今回はEC2自体がパブリックにあるため不要です。

VPC エンドポイント: なし

画面右側にプレビューが表示されます。「VPC」「サブネット」「ルートテーブル」「インターネットゲートウェイ」が含まれていることを確認し、「VPC を作成」 をクリックしてください。

完了画面が出たら成功です。

Step 3: EC2インスタンスの立ち上げ
ネットワークという「土地」ができたので、そこに「家（サーバー）」を建てます。

AWSコンソール左上の検索バーで「EC2」と入力して移動します。

オレンジ色のボタン 「インスタンスを起動」 をクリックします。

以下の設定で、Webサーバー兼DBサーバーとなるマシンを作成します。

1. 名前とOS
名前: olist-web-server

OS (AMI): Ubuntu を選択

バージョン: Ubuntu Server 24.04 LTS (HVM) など、最新のLTS（長期サポート版）を選びます。Amazon Linuxも良いですが、Next.js/Node.js等のドキュメントが豊富なUbuntuが初心者には扱いやすいです。

2. インスタンスタイプ
インスタンスタイプ: t2.micro または t3.micro

無料利用枠の対象になっているものを選んでください。

3. キーペア (ログイン用の鍵)
キーペア名: 新しいキーペアの作成 をクリック

名前: olist-key

タイプ: RSA

形式: .pem (Mac/Linux用) または .ppk (Windows + PuTTY用)

WindowsでもPowerShellやVSCodeを使うなら .pem で大丈夫です。

「キーペアを作成」 をクリックすると、ファイルがダウンロードされます。

⚠️ 重要: このファイルは絶対に無くさないでください。 再発行できません。PCの安全な場所（~/.ssh/ など）に保存してください。

4. ネットワーク設定 (重要！)
「編集」ボタンを押して、先ほど作ったVPCを指定します。

VPC: olist-project-vpc (先ほど作ったもの)

サブネット: olist-project-subnet-public1 (必ずパブリックを選んでください)

パブリック IP の自動割り当て: 有効化 (これがないとネットからアクセスできません)

ファイアウォール (セキュリティグループ):

セキュリティグループを作成する を選択

グループ名: olist-sg-web

説明: Allow SSH and HTTP

インバウンドセキュリティグループのルール:

タイプ: ssh (ポート22) | ソース: 自分のIP (安全のため、自宅のIPのみに限定することを強く推奨します)

タイプ: HTTP (ポート80) | ソース: 任意の場所 (0.0.0.0/0)

タイプ: HTTPS (ポート443) | ソース: 任意の場所 (0.0.0.0/0)

タイプ: カスタムTCP | ポート: 3000 | ソース: 自分のIP

解説: 開発中の確認用にNext.jsのポート3000を開けておきます。

5. ストレージ
8 GiB (デフォルト) でOKですが、DBも同居させるので余裕を持って 20 GiB にしておくと安心です（無料枠は30GiBまで）。

最後に画面右側の 「インスタンスを起動」 をクリックしてください。

Step 4: 接続確認
インスタンスの状態が「実行中」になったら、接続してみましょう。

インスタンス一覧から作成したインスタンスを選択し、「パブリック IPv4 アドレス」 をコピーします（例: 54.123.45.67）。

ご自身のPCのターミナルを開きます。

ダウンロードしたキーペア（olist-key.pem）がある場所に移動します。

キーの権限を変更します（Mac/Linuxの場合必須）。

Bash

chmod 400 olist-key.pem
SSHで接続します。

Bash

ssh -i "olist-key.pem" ubuntu@<コピーしたパブリックIP>
Are you sure you want to continue connecting? と聞かれたら yes と入力。

ubuntu@ip-10-0-1-xx:~$ のような表示が出れば、無事にAWSのサーバーに入ることができました！
